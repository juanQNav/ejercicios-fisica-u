# Ejercicios de Física Universitaria

Plataforma interactiva para resolver ejercicios del libro **Física Universitaria** de Sears & Zemansky (12a edición). Diseñada para que practiques paso a paso y verifiques tus respuestas.

**En vivo:** https://juanqnav.github.io/ejercicios-fisica-u/

## Características

- **23 ejercicios** de los Capítulos 1, 2 y 3
- **Resolución paso a paso** — cada paso se despliega individualmente para que practiques antes de ver la respuesta
- **Diagramas SVG** para cada ejercicio
- **Consejos** y tips para cada problema
- **Progreso guardado** en localStorage — no perdés tu avance al cerrar el navegador
- **Diseño responsivo** — funciona en desktop, tablet y móvil
- **Dark mode** — cómodo para estudiar de noche
- **Archivo único** — un solo HTML, sin dependencias externas

## Cómo usar

1. Abrí la página en tu navegador
2. Seleccioná el capítulo en la barra de navegación
3. Expandí un ejercicio haciendo clic en el título
4. Leé el problema y revisá el diagrama
5. Abrí cada paso de la resolución para entender el método
6. **Escribí tu respuesta** antes de verificar
7. Compará con la respuesta correcta y marcá si lo resolviste bien
